## 本轮封存与备份更新

本分支新增 Gitee 显式封存开关与独立备份 worker 开关，均仅精确 `1` 启用，默认关闭。细节与默认限额见[组织仓库说明](../repository-provisioning.md)。预览核对数字仓库身份、先保护入口再按原 SHA 建引用；确认按服务器可信 `receivedAt` 判断截止并只写本地数据，`savedAt` 保留实际保存时间。后续 push 不会替换已预览的版本。GitHub、旧手填、评分/投票、历史和回执重放保持兼容，已有正式 v1 不回填。

页面分开显示“版本已封存”和独立备份 queued / running / ready / partial / failed。旧回执只显示自身封存与接收/保存时间；最新备份另标正式版号，历史查所选版。刷新只改备份小块，保留未保存材料和人工备注，并校验会话、浏览器登录标记、路由、组件和版本。固定 commit 链接不跟随分支 head；私有下载只接受同源部署前缀内的本队/本版 API。

Gitee 原仓库是外部开源仓库，新增服务器备份文件为私有存储，仅本队和组织方可下载。Git 依赖、重试、容量限制、重启恢复及精确 SHA 打包见上述操作说明。ready 只证明 Git 字节已保存和校验；partial 明列未抓取的 LFS/子模块，均不证明项目可运行，不包含 PPT/视频。本次不新增自动公开备份或作品集，后续公开仍须组织方逐队逐正式版本确认。PDF/PPT 未重新生成，旧教学稿不能代替新页面状态说明。

## 恢复工作时先处理的两项问题

独立审查定位和理由见上面的审查文档。先修复，再进行生产发布：

1. `installRepositoryAdmin` 应捕获管理员会话对象，并在渲染和操作前核对 `session === owner && ownsBrowserLogin(owner)`，避免另一标签页换号后展示旧管理员响应中的队伍与账号映射。还需要补延迟响应的跨标签登录回归。
