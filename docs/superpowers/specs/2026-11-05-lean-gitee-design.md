# Gitee 仓库优先授权与轻量提交
主办方核对本队用户名后通过 API 在既有企业下建仓；先给仓库 push，只有明确要求企业成员时才邀请普通成员。可接受的结果包括待选手确认和人工核对；不能把普通 403、限流或不确定结果当作入企依据。绝不赋管理员、修改已有企业角色或按邮箱新建账号。无外部账号时不可宣称已验证自动入企或免费席位。

绑定 Gitee 的队伍使用 Git 推送，把 README、许可证和第三方来源写入代码仓库。官网自动定位固定 SHA，不要求再填这组字段；保留手填等旧路径、原提交时间、封存保护和历史回执。新增自动源码备份在正式服务关闭，不新建排队记录，不影响已有私有下载。选手以成功回执及固定版本为准。部署前回归；提交独立 PR。
